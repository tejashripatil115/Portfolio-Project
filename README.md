## 🌐 Free Hosting on GitHub Pages (Takes 2 minutes)

1. Create a new repository on your GitHub account: [https://github.com/new](https://github.com/new) named `portfolio` (or `tejashripatil115.github.io`).
2. Push these files to your repository:
   ```bash
   git init
   git add .
   git commit -m "Launch clean personal portfolio"
   git branch -M main
   git remote add origin https://github.com/tejashripatil115/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio will be live at:
   `https://tejashripatil115.github.io/portfolio/`
